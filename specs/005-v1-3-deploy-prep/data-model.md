## 1. 핵심 엔티티

### 1.1 사고일시 원본 (AccidentDatetime)

CSV train/test 데이터에 포함된 원본 컬럼.

| 속성 | 타입 | 설명 | 예시 |
|------|------|------|------|
| 사고일시 | string | "yyyy-mm-dd HH" 형식 | "2022-01-01 08" |

**유효성 규칙**:
- 형식: `{4자리 연도}-{2자리 월}-{2자리 일} {2자리 시간}`
- 연도: 2000-2099
- 월: 01-12
- 일: 01-31
- 시간: 00-23

### 1.2 파생 피처 (DerivedFeatures)

사고일시에서 추출된 ML 모델 입력 피처.

| 속성 | 타입 | 설명 | 예시 |
|------|------|------|------|
| 사고연 | int | 연도 | 2022 |
| 사고월 | int | 월 (1-12) | 1 |
| 사고일 | int | 일 (1-31) | 15 |
| 사고시 | int | 시간 (0-23) | 8 |
| 시간대 | string | 범주형 분류 | "출근시간대" |

**유효성 규칙**:
- 사고연: 2000 ≤ 값 ≤ 2099
- 사고월: 1 ≤ 값 ≤ 12
- 사고일: 1 ≤ 값 ≤ 31
- 사고시: 0 ≤ 값 ≤ 23
- 시간대: {"출근시간대", "퇴근시간대", "심야", "일반시간대"} 중 하나

### 1.3 시간대 분류 (TimePeriod)

사고시 값에 따른 범주형 분류.

| 시간대 | 조건 | 설명 |
|--------|------|------|
| 출근시간대 | 7 ≤ 사고시 ≤ 9 | 아침 출근 시간 |
| 퇴근시간대 | 17 ≤ 사고시 ≤ 19 | 저녁 퇴근 시간 |
| 심야 | 사고시 ≥ 22 또는 사고시 ≤ 5 | 야간/새벽 |
| 일반시간대 | 그 외 | 일반 시간 |

## 2. 데이터 흐름

```
CSV 업로드 (train.csv / test.csv)
    │
    ▼
read_uploaded_csv()
    │
    ▼
preprocess_accident_datetime()
    │
    ├── "사고일시" 컬럼 존재?
    │   ├── Yes → 파싱 및 파생 피처 생성
    │   └── No → 원본 반환
    │
    ▼
st.session_state['datasets']['train' or 'test']
    │
    ▼
ML 모델 추론 (predict_eclo)
```

## 3. 상태 전이

### 3.1 데이터셋 상태

```
[미업로드] → [업로드됨] → [전처리됨] → [캐싱됨]
                          │
                          └── 전처리 실패 시 → [원본 캐싱됨]
```

### 3.2 전처리 상태

| 상태 | 설명 | session_state 값 |
|------|------|------------------|
| 미업로드 | 데이터 없음 | `None` |
| 전처리됨 | 파생 피처 포함 | DataFrame (5개 컬럼 추가) |
| 원본 캐싱됨 | 전처리 건너뜀 | DataFrame (원본 그대로) |

## 4. 관계도

```

│                      train/test CSV                      │

│ - 사고일시 (string)          → 입력                      │

│ - 기타 컬럼들                                            │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                  전처리된 DataFrame                      │
├─────────────────────────────────────────────────────────┤
│ - 사고일시 (datetime)        → 변환됨                   │
│ - 사고연 (int)               → 추출됨                   │
│ - 사고월 (int)               → 추출됨                   │
│ - 사고일 (int)               → 추출됨                   │
│ - 사고시 (int)               → 추출됨                   │
│ - 시간대 (string)            → 파생됨                   │
│ - 기존 컬럼들                 → 유지                     │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                     ML 모델 (LightGBM)                   │
├─────────────────────────────────────────────────────────┤
│ 필요 피처:                                               │
│ - 범주형: 기상상태, 노면상태, 도로형태, 사고유형,         │
│          시간대, 시군구, 요일                            │

```
