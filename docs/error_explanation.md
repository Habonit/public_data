# 에러 명세서

앱에서 발생할 수 있는 에러 상황과 처리 방법을 정의합니다.

---

## 1. 데이터 로딩 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| CSV 파일 읽기 실패 | `UnicodeDecodeError` | 인코딩 불일치 | "파일 인코딩을 확인해주세요 (UTF-8, CP949 지원)" | 해당 데이터셋만 업로드 실패 처리 |
| 빈 파일 업로드 | `pd.errors.EmptyDataError` | 파일 내용 없음 | "빈 파일입니다. 데이터가 포함된 파일을 업로드해주세요" | 해당 데이터셋만 업로드 실패 처리 |
| 잘못된 파일 형식 | `pd.errors.ParserError` | CSV 형식 아님 | "CSV 형식이 아닙니다. 파일 형식을 확인해주세요" | 해당 데이터셋만 업로드 실패 처리 |
| 파일 없음 | `FileNotFoundError` | 경로 오류 | "파일을 찾을 수 없습니다" | 해당 데이터셋만 로딩 실패 처리 |

---

## 2. 데이터 전처리 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| 사고일시 컬럼 없음 | `KeyError` | 필수 컬럼 누락 | "사고일시 컬럼이 없습니다" | 전처리 건너뛰고 원본 데이터 사용 |
| 날짜 파싱 실패 | `ValueError` | 날짜 형식 불일치 | "날짜 형식이 올바르지 않습니다 (예: 2022-01-01 01)" | 해당 행만 제외하고 처리 |
| 데이터 타입 변환 실패 | `TypeError` | 타입 불일치 | "데이터 타입 변환에 실패했습니다" | 해당 컬럼 전처리 건너뜀 |

---

## 3. ML 모델 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| 모델 파일 없음 | `FileNotFoundError` | model/*.pkl 누락 | "예측 모델을 찾을 수 없습니다" | ECLO 예측 기능 비활성화 |
| 모델 로딩 실패 | `pickle.UnpicklingError` | 파일 손상 | "모델 파일이 손상되었습니다" | ECLO 예측 기능 비활성화 |
| 필수 피처 누락 | `KeyError` | 입력 데이터 컬럼 부족 | "예측에 필요한 컬럼이 누락되었습니다: {컬럼명}" | 예측 실행 안 함, 누락 컬럼 안내 |
| 인코더 불일치 | `ValueError` | 학습 시 없던 카테고리 | "알 수 없는 카테고리 값입니다: {값}" | 해당 행 예측 제외 |

## 4. AI 챗봇 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| API Key 미입력 | - | 사용자 미입력 | "사이드바에서 API Key를 입력해주세요" | 챗봇 탭 기능 제한, 다른 탭 정상 |
| API Key 형식 오류 | `AuthenticationError` | 잘못된 키 형식 | "API Key 형식이 올바르지 않습니다" | 챗봇 탭 기능 제한 |
| API 호출 실패 | `APIError` | 네트워크/서버 오류 | "AI 서비스 연결에 실패했습니다. 잠시 후 다시 시도해주세요" | 재시도 안내 |
| Rate Limit 초과 | `RateLimitError` | 요청 한도 초과 | "요청 한도를 초과했습니다. 잠시 후 다시 시도해주세요" | 대기 시간 안내 |
| Tool 실행 실패 | `ToolExecutionError` | 도구 내부 오류 | "데이터 분석 중 오류가 발생했습니다" | 일반 응답으로 폴백 |

## 5. 시각화 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| 좌표 컬럼 미감지 | - | 위도/경도 컬럼 없음 | "지리 좌표가 감지되지 않았습니다" | 지도 시각화만 비활성화 |
| 좌표 값 오류 | `ValueError` | 범위 벗어난 좌표 | "좌표 값이 유효하지 않습니다" | 해당 포인트 제외하고 지도 표시 |
| 숫자형 컬럼 없음 | - | 수치 데이터 없음 | "숫자형 컬럼이 없습니다" | 숫자 분포 차트만 비활성화 |
| 범주형 컬럼 없음 | - | 범주 데이터 없음 | "범주형 컬럼이 없습니다" | 범주형 분포 차트만 비활성화 |

## 6. 세션/상태 에러

| 에러 상황 | 예외 타입 | 원인 | 사용자 메시지 | Graceful Degradation |
|:----------|:----------|:-----|:-------------|:--------------------|
| 세션 데이터 없음 | `KeyError` | 데이터셋 미업로드 | "먼저 데이터를 업로드해주세요" | 해당 탭 기능 제한 안내 |
| 캐시 만료 | - | 세션 타임아웃 | "세션이 만료되었습니다. 데이터를 다시 업로드해주세요" | 업로드 탭으로 안내 |

## 에러 처리 코드 예시

```python
def load_and_preprocess_data(uploaded_file) -> pd.DataFrame:
    """데이터 로딩 및 전처리 (Graceful Degradation 적용)"""

    # 1. 파일 로딩
    try:
        df = read_uploaded_csv(uploaded_file)
    except UnicodeDecodeError:
        st.error("파일 인코딩을 확인해주세요 (UTF-8, CP949 지원)")
        return None
    except pd.errors.EmptyDataError:
        st.error("빈 파일입니다. 데이터가 포함된 파일을 업로드해주세요")
        return None
    except pd.errors.ParserError:
        st.error("CSV 형식이 아닙니다. 파일 형식을 확인해주세요")
        return None

    # 2. 전처리 (실패 시 원본 반환)
    try:
        df = preprocess_accident_datetime(df)
    except KeyError as e:
        st.warning(f"전처리 건너뜀: {e} 컬럼이 없습니다")
        # 원본 데이터 그대로 사용 (Graceful Degradation)
    except ValueError as e:
        st.warning(f"일부 행의 날짜 형식이 올바르지 않아 제외되었습니다")
        # 파싱 가능한 행만 사용

    return df
```
