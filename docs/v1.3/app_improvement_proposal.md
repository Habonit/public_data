# 대구 공공데이터 시각화 앱 개선 제안서 (v1.2.7 → v1.3)

**문서 버전**: v1.3
**작성일**: 2025-12-11
**참고 문서**: `docs/v1.3/note.md`

## 1. 개요

본 문서는 대구 공공데이터 시각화 앱 v1.2.7의 현재 상태(AS-IS)와 v1.3에서 목표하는 개선 상태(TO-BE)를 비교 분석한다.

### 핵심 목표

1. **P0 - Streamlit Community 배포 준비**: 앱의 안정적 배포를 위한 환경 정비
2. **P0 - ML 모델 전처리 개선**: 사고일시 데이터 파싱 및 파생 피처 생성
3. **P1 - 프로젝트 개요 콘텐츠 보강**: 데이터 출처 및 앱 설명 추가

## 2. 기능별 AS-IS / TO-BE 비교

### 2.1 사고일시 데이터 전처리

| 구분 | AS-IS (v1.2.7) | TO-BE (v1.3) |
|:-----|:---------------|:-------------|
| 사고일시 파싱 | 문자열 그대로 사용 또는 datetime 변환만 | 연/월/일/시 4개 컬럼으로 분리 |
| 시간대 분류 | 미구현 | 출근시간대/퇴근시간대/심야/일반시간대 범주형 컬럼 생성 |
| 데이터 형식 | `{yyyy-mm-dd HH}` 문자열 | 사고연(int), 사고월(int), 사고일(int), 사고시(int), 시간대(str) |

#### 2.1.1 사고일시 파싱 규칙

현재 데이터 형식 예시: `"2022-01-01 01"`

**파싱 결과:**
| 원본 | 사고연 | 사고월 | 사고일 | 사고시  | 시간대 |
|:-----|:-------|:-------|:-------|:-----|:-------|
| 2022-01-01 01 | 2022 | 1 | 1 | 1 | 심야 |
| 2022-03-15 08 | 2022 | 3 | 15 | 8  | 출근시간대 |
| 2022-06-20 14 | 2022 | 6 | 20 | 14 | 일반시간대 |
| 2022-09-10 18 | 2022 | 9 | 10 | 18 | 퇴근시간대 |

#### 2.1.2 시간대 분류 로직

```python
def hour_to_period(h):
    if 7 <= h <= 9:
        return "출근시간대"
    elif 17 <= h <= 19:
        return "퇴근시간대"
    elif 22 <= h or h <= 5:
        return "심야"
    else:
        return "일반시간대"
```

## 3. 코드 품질 개선

### 3.1 데이터 전처리 파이프라인 추가

| 위치 | AS-IS (v1.2.7) | TO-BE (v1.3) | 심각도 |
|:-----|:---------------|:-------------|:-------|
| `utils/` | 전처리 유틸리티 미분리 | `utils/preprocessing.py` 신규 생성 | 🔧 개선 |
| 데이터 로딩 | 원본 그대로 저장 | 업로드 시 자동 전처리 적용 | 🔧 개선 |

#### 3.1.1 전처리 함수 설계

```python
# AS-IS
# 별도의 전처리 없이 원본 데이터 사용

# TO-BE
def preprocess_accident_datetime(df: pd.DataFrame) -> pd.DataFrame:
    """
    사고일시 컬럼을 파싱하여 파생 피처 생성

    Args:
        df: 원본 DataFrame (사고일시 컬럼 포함)

    Returns:
        전처리된 DataFrame (사고연, 사고월, 사고일, 사고시, 시간대 추가)
    """
    if '사고일시' not in df.columns:
        return df

    # datetime 변환
    df['사고일시'] = pd.to_datetime(df['사고일시'])

    # 파생 피처 생성
    df['사고연'] = df['사고일시'].dt.year
    df['사고월'] = df['사고일시'].dt.month
    df['사고일'] = df['사고일시'].dt.day
    df['사고시'] = df['사고일시'].dt.hour
    df['시간대'] = df['사고시'].apply(hour_to_period)

    return df
```
