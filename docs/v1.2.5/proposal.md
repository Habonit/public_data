# AI 챗봇 보고서 생성 기능 제안서

**작성일**: 2025-12-10

---

## 1. 개요

사용자가 AI 챗봇에게 해당 데이터에 대한 심층 보고서를 생성 의사를 표현하면, 대화를 통해 요구사항을 수집하고 마크다운 형태로 보고서를 작성/수정하며 사용자 컨펌 시까지 반복하는 기능.

---

## 2. 기능 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 사용자: 보고서 생성 의사 표현                                  │
│     예: "보고서 만들어줘", "분석 결과 정리해줘"                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  2. AI: 적극적 재질문 (예시 제시)                                  │
│                                                                  │
│     📌 주제                                                      │
│     "어떤 주제를 가지고 데이터 분석을 위한 보고서를 작성할까요?"         │
│     예) 특징 간의 연관선 분석, 데이터 분석 결과, 다양한 관점 제공 및 가설 수립 등등 │
│                                                                  │
│     📌 스타일                                                     │
│     "어떤 톤/스타일로 작성할까요?"                                  │
│     예) 공식적/격식체, 캐주얼/친근한, 학술적/논문형,                 │
│         비즈니스/간결한, 설명적/교육용                              │
│                                                                  │
│     📌 형태                                                       │
│     "어떤 구조로 작성할까요?"                                      │
│     예) 요약형(1페이지), 표준형(3-5페이지), 상세형(10페이지+),       │
│         비교분석형(특징이나 지리적 위치 분석 강조), 타임라인형(시계열 데이터 강조), Q&A │
│                                                                  │
│     📌 분량                                                       │
│     "대략 어느 정도 분량을 원하시나요?"                             │
│     예) 짧게(항목 당 100자), 보통(항목 당 100-500자), 길게( 항목 당 500자+)  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  3. 사용자: 요구사항 답변                                         │
│     (충분한 정보가 모일 때까지 대화 반복)                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  4. AI: 마크다운 보고서 작성 및 출력                               │
│                                                                  │
│     - 채팅창에 마크다운 보고서 전문 출력                            │
│     - [마크다운 다운로드] 버튼 함께 제공                            │
│     - "이 내용으로 괜찮으신가요?" 확인 요청                         │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  5. 사용자: 확인/수정 요청                                        │
│                                                                  │
│     - 수정 요청 → 4단계로 돌아가 수정본 재출력                      │
│       (수정본에도 [마크다운 다운로드] 버튼 제공)                     │
│     - OK → 완료                                                  │
└─────────────────────────────────────────────────────────────────┘
```

---

## 3. 필요한 Tool

| Tool 이름 | 용도 |
|:----------|:-----|
| `ask_report_requirements` | 주제/스타일/형태/분량 질문 (예시 포함) |

---

## 4. 출력물

| 형식 | 제공 시점 |
|:-----|:----------|
| 마크다운 (.md) | 매 출력마다 다운로드 가능 |

---

## 5. 구현 우선순위

### P0 - 핵심 기능

| 항목 | 설명 |
|:-----|:-----|
| 보고서 생성 의도 감지 | 사용자의 보고서 생성 의사 표현 인식 |
| 요구사항 수집 Tool | 주제/스타일/형태/분량 질문 및 예시 제시 |
| 마크다운 보고서 생성 | 수집된 요구사항 기반 보고서 작성 |

### P1 - 사용자 경험

| 항목 | 설명 |
|:-----|:-----|
| 마크다운 다운로드 버튼 | 매 출력마다 다운로드 기능 제공 |
| 컨펌 루프 | 사용자 확인/수정 요청 처리 |
