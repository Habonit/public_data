# 대구 공공데이터 시각화 앱 개선 제안서 (v1.2.3 → v1.2.4)

**문서 버전**: v1.2.4
**작성일**: 2025-12-09
**참고 문서**: `docs/v1.2.4/note.md`

---

## 1. 개요

본 문서는 대구 공공데이터 시각화 앱 v1.2.3의 현재 상태(AS-IS)와 v1.2.4에서 목표하는 개선 상태(TO-BE)를 비교 분석한다.

v1.2.4의 핵심 목표:
1. **버그 수정**: 테스트 데이터(test.csv) 업로드 시 헤더가 데이터 행으로 인식되는 문제 해결
2. **버그 수정**: 데이터 질의응답 탭에서 데이터셋 변경 시 요약이 업데이트되지 않는 문제 해결
3. **기능 개선**: 데이터셋 요약에 샘플 데이터 10개 표시

---

## 2. 기능별 AS-IS / TO-BE 비교

### 2.1 테스트 데이터 업로드 기능

| 구분 | AS-IS (v1.2.3) | TO-BE (v1.2.4) |
|:-----|:---------------|:---------------|
| **헤더 인식** | test.csv 업로드 시 첫 행이 데이터로 인식됨 | 첫 행이 정상적으로 컬럼명으로 인식됨 |
| **컬럼명** | `0`, `1`, `2`, ... (숫자 인덱스) | `ID`, `사고일시`, `요일`, `기상상태`, `시군구`, `도로형태`, `노면상태`, `사고유형` |
| **데이터 행** | 헤더 행이 첫 번째 데이터로 포함됨 | 실제 데이터만 포함됨 |

│ ID │ 사고일시         │ 요일   │ 기상상태 │ 시군구    │ 도로형태 │ 노면상태 │ 사고유형 │  ← 헤더가 데이터 행으로!
│ .. │ ...              │ ...    │ ...      │ ...       │ ...      │ ...      │ ...      │
└────┴──────────────────┴────────┴──────────┴───────────┴──────────┴──────────┴──────────┘

### 2.2 데이터 질의응답 - 데이터셋 변경 시 요약 갱신

| 구분 | AS-IS (v1.2.3) | TO-BE (v1.2.4) |
|:-----|:---------------|:---------------|
| **데이터셋 선택 변경** | 요약이 갱신되지 않음 | 선택한 데이터셋의 요약으로 즉시 갱신 |
| **사용자 경험** | 이전 데이터셋 정보가 유지되어 혼란 | 선택과 동시에 해당 데이터셋 정보 표시 |
| **상태 관리** | 데이터셋 변경 시 요약 상태 미동기화 | session_state 기반 동기화 |

#### 2.2.1 문제 시나리오

**AS-IS (v1.2.3)**
```
1. 사용자가 'CCTV' 데이터셋 선택
2. CCTV 데이터셋 요약 정상 표시
3. 사용자가 셀렉트박스에서 '보안등' 선택
4. 데이터셋 요약이 갱신되지 않음 (빈 화면 또는 이전 데이터 유지)
```

**TO-BE (v1.2.4)**
```
1. 사용자가 'CCTV' 데이터셋 선택
2. CCTV 데이터셋 요약 정상 표시
3. 사용자가 셀렉트박스에서 '보안등' 선택
4. 보안등 데이터셋 요약 즉시 갱신 표시
```

## 3. 코드 품질 개선

### 3.1 버그 원인 분석

| 위치 | 문제 | 심각도 |
|:-----|:-----|:-------|
| `utils/loader.py:read_uploaded_csv()` | 특정 조건에서 헤더 미인식 | 🔴 Error |
| `app.py:데이터 질의응답 탭` | 데이터셋 변경 시 요약 갱신 안됨 | 🔴 Error |
| `app.py:데이터셋 요약` | 샘플 데이터 표시 부족 | ⚠️ Warning |

#### 3.1.1 test.csv 헤더 인식 문제 해결 방안

**가능한 원인들:**
1. **BOM(Byte Order Mark) 문제**: UTF-8-BOM 파일에서 첫 행 인코딩 문제
2. **파일 포인터 위치**: 업로드 파일의 seek 위치 문제
3. **pandas read_csv 옵션**: `header` 파라미터 명시 필요

**코드 수정 방안:**
```python
# AS-IS
def read_uploaded_csv(uploaded_file: BinaryIO) -> pd.DataFrame:
    content = uploaded_file.read()
    for enc in encodings:
        try:
            df = pd.read_csv(io.BytesIO(content), encoding=enc)
            return df
        except UnicodeDecodeError as e:
            ...

# TO-BE
def read_uploaded_csv(uploaded_file: BinaryIO) -> pd.DataFrame:
    content = uploaded_file.read()
    for enc in encodings:
        try:
            df = pd.read_csv(
                io.BytesIO(content),
                encoding=enc,
                header=0  # 첫 행을 헤더로 명시적 지정
            )
            return df
        except UnicodeDecodeError as e:
            ...
```

#### 3.1.2 데이터셋 요약 갱신 문제 해결 방안

**예상 원인:**
- 셀렉트박스 변경 시 `on_change` 콜백 미설정
- 또는 요약 표시 로직이 변경 이벤트에 반응하지 않음

**수정 방향:**
```python
# 데이터셋 선택 시 key 변경을 통한 리렌더링 트리거
# 또는 on_change 콜백으로 요약 갱신 함수 호출
```

#### 3.1.3 샘플 데이터 10개 표시

```python
# AS-IS
st.dataframe(df.head())  # 기본 5개

# TO-BE
st.dataframe(df.head(10))  # 10개 표시
```
