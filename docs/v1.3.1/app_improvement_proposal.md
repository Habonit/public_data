# 대구 공공데이터 시각화 앱 개선 제안서 (v1.3 → v1.3.1)

**문서 버전**: v1.3.1
**작성일**: 2025-12-11
**참고 문서**: `docs/v1.3.1/note.md`

## 1. 개요

본 문서는 대구 공공데이터 시각화 앱 v1.3의 현재 상태(AS-IS)와 v1.3.1에서 목표하는 개선 상태(TO-BE)를 비교 분석한다. 주로 UI 문구 수정, 복사 기능 개선, Streamlit Deprecation Warning 해결, 문서 최신화를 다룬다.

### 2.2 프로젝트 개요 탭

| 구분 | AS-IS (v1.3) | TO-BE (v1.3.1) |
|:-----|:-------------|:---------------|
| 헤더 | `📖 프로젝트 개요` | 헤더 삭제 (탭 이름으로 충분) |
| 데이터 출처 설명 | train.csv, test.csv 2개 언급 | 총 7개 데이터셋 명시 (CCTV, 보안등, 어린이보호구역, 주차장, 사고, 훈련, 테스트) |
| 데이터 준비 방법 | train.csv, test.csv 중심 | 모든 데이터셋 다운로드 강조 |

#### 2.2.1 데이터 준비 방법 상세

**AS-IS:**
```
1. 위 DACON 대회 링크에 접속합니다
2. 대회 참가 후 데이터 탭에서 train.csv, test.csv를 다운로드합니다
3. 아래 데이터 업로드 섹션에서 파일을 업로드합니다
4. 훈련 데이터, 테스트 데이터 탭에서 데이터를 탐색합니다
5. 데이터 질의응답 탭에서 AI 챗봇에 ECLO 예측을 요청할 수 있습니다
```

**TO-BE:**
```
1. 위 DACON 대회 링크에 접속합니다
2. 대회 참가 후 데이터 탭에서 데이터를 다운로드합니다
3. 아래 데이터 업로드 섹션에서 파일을 업로드합니다
4. 업로드한 데이터에 대하여 EDA를 진행합니다
5. 데이터 질의응답 탭에서 AI 챗봇에 ECLO 예측을 요청할 수 있습니다
```

## 3. 코드 품질 개선

### 3.1 Streamlit Deprecation Warning 수정

| 위치 | AS-IS (v1.3) | TO-BE (v1.3.1) | 심각도 |
|:-----|:-------------|:---------------|:-------|
| `app.py` 전체 | `use_container_width=True` | `width='stretch'` | ⚠️ Warning |
| `app.py` 전체 | `use_container_width=False` | `width='content'` | ⚠️ Warning |

#### 3.1.1 코드 수정 상세

```python
# AS-IS
st.dataframe(df.head(10), use_container_width=True)

# TO-BE
st.dataframe(df.head(10), width='stretch')
```

**경고 메시지:**
```
Please replace `use_container_width` with `width`.
`use_container_width` will be removed after 2025-12-31.
```
