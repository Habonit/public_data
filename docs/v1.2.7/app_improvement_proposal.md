# 대구 공공데이터 시각화 앱 개선 제안서 (v1.2.6 → v1.2.7)

**문서 버전**: v1.2.7
**작성일**: 2025-12-10
**참고 문서**: `docs/v1.2.7/note.md`

---

## 1. 개요

본 문서는 대구 공공데이터 시각화 앱 v1.2.6의 현재 상태(AS-IS)와 v1.2.7에서 목표하는 개선 상태(TO-BE)를 비교 분석한다.

### 핵심 목표

1. **P0 - 긴 표 토글 UX**: AI 응답 내 긴 표로 인한 스크롤 문제 해결
2. **P1 - 도구 목록 UI 개선**: 22개 도구를 토글 형태로 변경, 각 도구 용도 3문장 설명
3. **P1 - LangGraph 워크플로우 다이어그램**: 시스템 흐름을 정확히 반영하는 다이어그램 업데이트

---

## 2. 기능별 AS-IS / TO-BE 비교

### 2.1 긴 표 토글 UX

| 구분 | AS-IS (v1.2.6) | TO-BE (v1.2.7) |
|:-----|:---------------|:---------------|
| 표 출력 방식 | 마크다운/데이터프레임 직접 렌더링 | `st.expander`로 토글 형태 |
| 기본 상태 | 항상 펼쳐진 상태 | 접힌 상태 (클릭 시 펼침) |
| 스크롤 | 긴 표 시 스크롤 문제 발생 | 토글로 접어서 스크롤 문제 해결 |
| 적용 범위 | - | 마크다운 테이블, 데이터프레임, 샘플 데이터 등 |

#### 2.1.1 문제 상황

```
┌─────────────────────────────────────────────────────────────┐
│  AI 응답                                                     │
│  ├─ "다음은 데이터 샘플입니다:"                                 │
│  ├─ [긴 표 50행...]  ← 스크롤이 제대로 작동 안 함               │
│  └─ "위 데이터를 보시면..."                                    │
└─────────────────────────────────────────────────────────────┘
```

#### 2.1.2 해결 방안

```
┌─────────────────────────────────────────────────────────────┐
│  AI 응답                                                     │
│  ├─ "다음은 데이터 샘플입니다:"                                 │
│  ├─ [▶ 표 보기] (토글 - 기본 접힘)                             │
│  │   └─ 클릭 시 펼쳐짐: [표 50행...]                          │
│  └─ "위 데이터를 보시면..."                                    │
└─────────────────────────────────────────────────────────────┘
```
