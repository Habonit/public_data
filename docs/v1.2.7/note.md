# 데이터 질의사항에서 표가 대답으로 출력되었을 때 출력 형태를 변경해야 함

  1. 문제: AI 응답에 긴 표가 포함될 경우 스크롤이 제대로 작동하지 않아 사용자 경험이 저하됨.
  2. 해결 방안: AI 응답 내 모든 표(테이블)를 Streamlit의 st.expander로 감싸서 토글 형태로 접고 펼 수 있게 구현.
  3. 기본 상태: 표는 기본적으로 접힌 상태로 표시하고, 사용자가 클릭하면 펼쳐지도록 설정.
  4. 적용 범위: 마크다운 테이블, 데이터프레임 출력, 샘플 데이터 등 모든 표 형식 응답에 적용.
  5. 기대 효과: 긴 표로 인한 스크롤 문제 해결 및 응답 가독성 향상.
